# Harshad Nimse - Developer Portfolio

A premium, interactive developer portfolio highlighting my expertise in **Full Stack Development** and **Data Engineering**. Built from scratch with HTML5, Vanilla CSS3, and modern JavaScript.

## 🚀 Live Demo
[View Live Portfolio](https://harshadnimse.github.io/Portfolio/)

## ✨ Features
- **Premium UI/UX:** Glassmorphism, animated gradients, custom cursor, and dynamic typing effects.
- **Dark/Light Mode:** Seamless theme switching with smooth transitions and persistent state.
- **Interactive Particle Canvas:** A custom HTML5 canvas background in the hero section that reacts to cursor movement.
- **Optimized Performance:** Built without heavy frameworks for blazing fast load times. Zero dependencies outside of Anime.js for micro-animations and Devicon for SVG icons.
- **Responsive Design:** Fluid typography and flex/grid layouts ensure perfect rendering across mobile, tablet, and desktop.
- **Dual Focus:** Highlights both Backend/Full Stack projects and Data Engineering/Automation workflows (like n8n ETL pipelines).

## 🛠️ Technology Stack
- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS3 (Custom properties, Flexbox, CSS Grid, animations, media queries)
- **Logic:** Vanilla ES6+ JavaScript
- **Animations:** [Anime.js](https://animejs.com/)

## 💻 Local Setup
To run this portfolio locally:
1. Clone the repository: `git clone https://github.com/HarshadNimse/Portfolio.git`
2. Navigate into the directory: `cd Portfolio`
3. Serve the directory with any local HTTP server, for example using Node.js:
   ```bash
   npx serve .
   ```
4. Open the provided localhost link in your browser.

## 📝 Customization
If you want to use this template as a base:
1. Replace `profile.jpeg` and `profile.png` with your own images.
2. Update the links in `index.html` (GitHub, LinkedIn, Email).
3. Replace the resume PDFs (`Harshad_Resume_J.pdf` and `Harshad_Resume_DataScience.pdf`) with your own.
4. Modify the skills in `index.html` and update the `data-target` attributes for the animated counters.
